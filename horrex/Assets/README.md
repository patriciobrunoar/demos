Drop the real Horrex brand assets in this folder:

- Logo (SVG or PNG, transparent background — light + dark variants if you have them)
- Favicon
- Product / hero / team photography
- Any icon set, brand guideline PDF, or imagery currently in use on horrex.nl
- Custom font files, if Horrex uses a licensed/non-Google font (otherwise the
  Google Fonts family identified during content extraction will be used)

Nothing in this folder is placeholder content. The site build will reference
files here by their real names once they're uploaded — nothing renders until
the actual asset exists.

## How to get these files

Easiest path: while running the Claude for Chrome extraction pass on
horrex.nl (see the prompt in `../content/README.md`), right-click and
"Save image as…" the logo, favicon, and any hero/product photos you want
used, then drop them straight into this folder (drag-and-drop into the chat,
or commit them to the branch on GitHub).
